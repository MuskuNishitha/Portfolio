Bootstrap still appears in many React projects, especially admin panels and older product screens. The main job is to work with its grid instead of layering random custom CSS over it.

![Bootstrap grid layout illustration with responsive rows and columns](/assets/blog/bootstrap-react-layout-cleanup.svg "Bootstrap grid layout illustration with responsive rows and columns")

## The Checklist

I first identify which parts are Bootstrap structure and which parts are product-specific UI. Container, row, column, and gap utilities should handle layout; component CSS should handle the product card or form.

## A Practical Pattern

When a screen is already Bootstrap-based, I keep the grid predictable and wrap custom React components inside the columns. That prevents the component from needing to know every breakpoint.

```jsx
<div className="container py-4">
  <div className="row g-4">
    <aside className="col-12 col-lg-3">Filters</aside>
    <main className="col-12 col-lg-9">Product grid</main>
  </div>
</div>
```

## Common Mistakes

- Putting fixed widths inside Bootstrap columns.
- Mixing grid classes with unrelated absolute positioning.
- Changing Bootstrap spacing globally for one screen.
- Forgetting that modals and dropdowns need keyboard and focus behavior checked.

## Before Shipping

If the long-term direction is Tailwind or custom CSS, I migrate screen by screen. A half-migrated layout is where most spacing bugs come from.
